# Real media replacement guide

The generated site uses original SVG diagrams so that no page has a broken image. Before public release, add only media approved for public display. Suggested filenames:

- `prototype-device.jpg` — current sensing hardware
- `android-app.jpg` — Android workflow screenshots
- `testing-setup.jpg` — calibration/testing setup
- `demo.mp4` — 30–60 second no-download demo
- `community-event.jpg` — approved community activity image
- `team-henry.jpg`, `team-tiger.jpg`, `team-elsa.jpg` — optional approved portraits

Do not publish any photo, chart, or participant information without the documented permission check.
