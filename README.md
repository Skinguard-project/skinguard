# SkinGuard

SkinGuard is a student-led, collaborative health-tech engineering project exploring longitudinal, non-diagnostic skin-condition monitoring and personal self-care intelligence.

The current Phase 1 prototype integrates:

- portable physiological sensing;
- environmental context;
- image-based analysis;
- an Android measurement workflow;
- the Skin Condition Index (SCI);
- structured longitudinal records.

The project investigates how repeated measurements can help users recognize personal patterns over time rather than produce diagnostic outputs.

**https://skinguard-project.github.io/skinguard/**

## Development roadmap

1. **Phase 1 — Completed:** integrated monitoring prototype and preliminary technical and longitudinal feasibility testing.
2. **Phase 2 — Planned:** expanded user data, tested personalization and guidance, and forecast-informed context.
3. **Phase 3 — Planned:** repeatability, reliability, manufacturability, and product-readiness work.

## Current boundary

SkinGuard is a preliminary, non-diagnostic engineering prototype. It does not claim clinical equivalence, treatment benefit, causality, flare prediction, or demonstrated health outcomes.
