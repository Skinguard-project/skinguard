SAFETY & PRIVACY

Clear limits are part of responsible engineering

SkinGuard is a preliminary, non-diagnostic student engineering project. Privacy and safety boundaries are part of the design—not footnotes.

CURRENT

Data sources

Project data includes the student researcher, family members, volunteers, and publicly available image data. Public images and longitudinal user records are described as different data sources.

CURRENT

Consent

User participation was conducted with consent. For minors, parental consent confirmation was obtained.

CURRENT

De-identification

User names were removed. Public reporting avoids showing identifiers that would allow participants to be re-identified.

CURRENT

Public display

Only photos, charts, and activity images confirmed for public display should appear on the website. Unconfirmed materials are not published.

CURRENT

Clinical boundary

No diagnosis, treatment advice, medication decision, clinical equivalence, causality, or health-outcome claim.

FUTURE

Expanded validation

Phase 2–3 work should include prospective consent, clear withdrawal options, privacy review, clinician-defined endpoints where appropriate, and suitable oversight.

DISCLOSURE CONTROL

Storage and cloud-processing language must match the research manuscript

The final public wording for storage, access, third-party cloud services, image transfer, health-related fields, and retention should be copied from the verified manuscript description without inference or expansion.

Publication checklist: synchronize these exact statements before the public site replaces the current version.

Required final disclosure

  • Where raw and processed records are stored
  • Who can access them
  • Which data fields, if any, are sent to third-party services
  • Whether images are transmitted
  • Retention and deletion practice

This page intentionally does not invent details that are not included in the approved website plan.

NON-DIAGNOSTIC BOUNDARY

Forecast-informed does not mean flare prediction

In Phase 2, weather forecasts are planned as contextual inputs to be tested for incremental value. They will not be presented as medical advice, treatment guidance, or prediction of flares or clinical outcomes.
